# 命运牌局 / Fatebound Gambit

东方无限流轻策略卡牌冒险游戏 · 手机竖屏

命运牌阵探索 + 牌型共鸣斗法 + 基地局外成长

## 现在就能玩

网页 Demo：https://andrewzheng418.github.io/FateboundGambit_Demo/

把地址贴到浏览器即可（建议手机竖屏，电脑也可以）。第一次打开可能要等几秒加载图片和音乐。

## 电脑本地打开

Windows 电脑自带 PowerShell 即可，不需要安装 Python / Node。

1. 进入本文件夹
2. 双击 `start_game.bat`
3. 浏览器会自动打开 `http://localhost:8765/`
4. **保持黑色命令行窗口不要关**

不要直接双击 `index.html`（部分浏览器会拦本地资源加载）。

若 `start_game.bat` 一闪而过：

- 右键「使用 PowerShell 运行」`start_game.ps1`
- 或检查是否被杀软拦截本机 HttpListener

若提示端口被占用：先运行 `关闭旧服务.bat`，再重新启动。8765 被占用时，脚本会自动改用 8766–8770。

若背景图 / 立绘不显示：一定要用 `start_game.bat` 打开，关掉旧黑窗口后重新启动，浏览器按 Ctrl+F5 强刷。

## 建议体验路径

1. 点「一键注册登录」（账号会是 test1、test2…，密码是 `1`，道号默认鸿明）
2. 想看开局故事就一直点继续；想快进，进地图后点底部「跳过新手」
3. 结算页点确定，进入青崖峰。先听青棠说完，点确认，再点功能入口
4. 命运阁可查看命运卡组
5. **世界之门**：组完卡后入世。红色牌是首领，在最上面。走到本层尽头会翻到下一层
   - 撤离：未达要求会失去本局奖励，需再确认一次
   - 暂时离开：保存进度，下次进世界之门可继续
6. **演武场**：先选传承、天时、地利、人和和最多 3 件宝物，再拼刀
   - 退出：丢掉本局回基地
   - 重开：丢掉本局，用同一套配置再打
   - 暂时离开：保存本局，下次接着打

## 存档说明

账号和进度都存在这台设备的浏览器里，没有联网存档。换浏览器或清缓存会看不到原来的号。网页版和本地版的存档也不会互相同步。
